# Stageplan Tool

Ein webbasiertes Planungstool für Bands, Tontechniker und Veranstaltungsteams. Mit dieser Anwendung lassen sich Auftrittstermine verwalten, Bühnenpläne (Stageplots) intuitiv per Drag-and-Drop erstellen und Benutzerrechte über ein zentrales Admin-Panel steuern.

---

## Features

* **Termin- und Eventverwaltung:** Erstellen, Bearbeiten und Verwalten von Gigs, Proben und Events inklusive persistenter Speicherung.
* **Drag & Drop Stageplan-Editor:** Visueller Editor zum einfachen Platzieren von Instrumenten, Mikrofonen, Monitoren und Equipment auf einer virtuellen Bühne.
* **Admin-Panel und Accountverwaltung:** Umfassender Administrationsbereich zur Verwaltung von Benutzerkonten, Rollen und Zugriffsrechten.
* **Leichtgewichtige Datenhaltung:** Alle Termine, Stagepläne und Benutzerdaten werden zuverlässig in einer lokalen SQLite-Datenbank gespeichert – ganz ohne aufwendige Datenbank-Server-Konfiguration.
